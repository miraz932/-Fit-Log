*Project Name: Fit Log stack Project

*Short Description: A user-friendly fitness web application designed to discover exercises, check workout information, and organize daily training activities.

*Technologies Used: Next.js, React, TypeScript, Tailwind CSS, Context API, React Icons, DaisyUI

*5 Key Features:

* Browse a variety of workout exercises
* Check complete information for each exercise
* Build a personal training routine
* Track and organize selected workouts
* Fully responsive layout for different devices
